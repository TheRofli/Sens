# Security policy

## Supported versions

Security fixes target the latest published Sens release. Older versions may not
receive backports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include a proof of
concept in public logs.

Use GitHub's private vulnerability reporting for this repository when it is
available:

<https://github.com/TheRofli/Sens/security/advisories/new>

If that route is unavailable, contact
[TheRofli through GitHub](https://github.com/TheRofli) and ask for a private
reporting channel. Share the affected version, impact, minimal reproduction,
and suggested mitigation. Remove unrelated API keys, IPC secrets, user media,
cookies, and personal data.

No response or disclosure deadline is promised. Please allow time to confirm
the report and prepare a safe update before public disclosure.
