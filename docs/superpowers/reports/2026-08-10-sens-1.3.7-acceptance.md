# Sens 1.3.7 web reconstruction acceptance

Date: 2026-08-10
Status: implementation, local release gates, signed packaging and installed
runtime verification passed; GitHub publication follows the final Git review.

## Release outcome

Sight now gives a text-only MCP host a measured web contract plus a generated
semantic HTML/CSS starter. Source glyphs are removed from protected background
artwork and rebuilt as live text. Visible controls are represented by semantic
HTML, while photos and illustrations remain bounded raster assets. Completion
requires both strict visual comparison and DOM/accessibility review.

The compact and brief projections use `jsonl-arrays` tables. Repeated values
are carried once in `constants`; a non-null `defaults` value applies when its
row cell is null. Full provenance remains available through `response=full`
and the materialized contract artifact.
